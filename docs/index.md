# API Reference

1. API Reference 的用途：本页汇总 `triton-anchor` 对外提供的 Python API。

2. 内容范围：涵盖核心编译能力、适配器和扩展机制。

3. 文档阅读方式：

    ```text
    APIName(parameter: Type) -> ReturnType
    Brief description.

    Parameters: parameter (Type) — Description.
    Returns: ReturnType — Description.
    Raises: ErrorType — Condition.
    ```

    第一行用于确认 API 名称、参数类型和返回类型，下一行说明 API 的主要功能。

    `Parameters`、`Returns` 和 `Raises` 分别说明输入参数、返回结果和可能出现的异常。
